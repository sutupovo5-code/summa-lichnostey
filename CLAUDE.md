# Сайт команды «Сумма Личностей» (ДЦ Липецк 2026)

Владелец — Иван (начинающий программист): объясняй просто, по шагам, отвечай по-русски.

## Как устроен
- Весь сайт — один файл `index.html` (~1 МБ, фото участников вшиты как base64). Публикуется через GitHub Pages из `main`.
- Стили: Tailwind с CDN (`cdn.tailwindcss.com`) + свои блоки `<style id="packN">`.
- Код собран **слоями**: `<script id="packNjs">`. Каждый следующий слой переопределяет функции предыдущих
  (`const _f=f; f=function(){ _f(); … }`). Новую доработку добавляй новым слоем в конец `<body>`,
  старые слои по возможности не трогай.
- Общая лента — Firebase (проект `summa-lich`), модуль `pack22mod`. Коллекции:
  - `posts` — посты: `post` (данные), `ownerUid`, `likesAdd`, `cm` (комментарии), `pv` (голоса), `top`, `del`.
    `top` = время в мс, когда пост сделали «новостью дня»; сайт сам гасит её в полночь по Москве (pack27).
  - `media` — видео к постам, нарезанное кусками ≤ 0,9 МБ (`{id}_{i}`), до 12 кусков.
  - `players` — рейтинг джекпотов и вид профиля (`look`).
- Правила базы — `firestore.rules`. **После правки их нужно вручную опубликовать** в консоли Firebase
  (Firestore Database → Rules → вставить → Publish). Без этого новые функции получают `permission-denied`.
- Баланс Σ, покупки магазина, настройки хранятся в `localStorage` телефона.

## Последний слой — pack27
Видео в постах (сжатие на телефоне до ~640p через MediaRecorder), пост без фото открывается без фото,
лента обновляет только изменившиеся посты, магазин на ~50 товаров (рамки/значки/цвет имени/карточки видны всем),
1 пост = 50 000 Σ (участники по коду публикуют бесплатно), профили других людей, новость дня до 00:00 мск,
мягкая палитра.

## pack28 (поверх pack27)
- Android: `body{overflow-x:clip}` — страница не шире экрана и при этом свайп листает окно (не возвращай `hidden` на body).
- Узкая шапка, кнопки в открытом посте в одну строку, поле комментария не вылезает.
- Карточки команды (`#sec-cards` после крутки): 10 участников × 6 скинов (классика, неон, хэллоуин, космос, золото, Дед Мороз/Снегурочка),
  редкости редкая/эпическая/мифическая/легендарная, 3 вида паков, альбом, разбор повторок. Хранятся в `localStorage` (`summa_cards_v1`).
- Хэллоуин в магазине: вкладка «🎃 Хэллоуин» — тема, летучие мыши, тыквенные искры, паутина, призрак, рамка, значки, цвет имени, карточка постов.

## pack29 (поверх pack28)
- Без приближения: `html,body{touch-action:pan-x pan-y}` + запрет щипка в JS; `<meta name="color-scheme" content="dark">` (браузер не «затемняет» сайт сам).
- Светлее: синий фон и панели вместо почти чёрных (перекрывает тёмную палитру pack27 на телефоне).
- Карточки v2 (`summa_cards_v2`, старые `summa_cards_v1` переносятся): «Пак персонажей» (2 участника) и «Пак скинов» (2 скина
  только для своих персонажей). 12 скинов: редкие (неон, ретро, комикс), эпические (хэллоуин, космонавт, киберпанк),
  мифические (золото, голограмма, пламя), легендарные (Дед Мороз/Снегурочка, Король/Королева, Супергерой).
- «О нас» для всех: коллекция `team` в Firebase (фото участника; заменить может только тот, кто загрузил первым).
  На телефоне, где в «О нас» свои фото, участнику (по коду) показывается кнопка «📤 Отправить фото всем».

## pack30 (поверх pack29)
- Шапка `position:fixed` (+ отступ `--hdrH`, `safe-area` для iPhone) — sticky на iPhone пропадал.
- `<meta name="color-scheme" content="dark">` в `<head>`: Android в тёмной теме больше не затемняет сайт.
- Облегчённый режим `html.sx-lite`: сам включается на слабых телефонах (мало памяти/ядер или < 40 кадров/с),
  переключатель «⚡ Плавность» в профиле. В альбоме карты не анимируются.
- Паки-бустеры (зубчатые края, фольга, лица участников), карты с камнем редкости, звёздами и табличкой имени.
- Крутка x5 (750 Σ) и x10 (1 400 Σ) вместо бесплатной «Быстро x10»; 1x — бесплатно.

## Проверка
Перед публикацией проверяй в мобильном виде (Android и iPhone): лента, открытый пост, редактор поста, магазин, профиль.
